# Voice Quality Assist 0.1.0-candidate.1

手元確認用の候補版です。公開配布用の正式リリースではありません。
実YMM4とテスト用VOICEVOXサーバーで動作経路を確認しますが、実際の話者の自然さ・発音改善率・すべての画面操作を保証するものではありません。

## 入れる前に

作業中のYMMPは別名でコピーして、そのコピーだけで試してください。最初から制作中の原本に適用しないでください。
検証対象は Windows / YMM4 4.56.1.0 Lite / YMM4標準のVOICEVOX話者です。VOICEVOXエンジンは利用者側で設定・起動してください。

YMM4を終了し、ZIP内の `Ymm4VoiceQualityAssist` フォルダーを、YMM4本体の `user/plugin/` の下へコピーします。
最終的に `user/plugin/Ymm4VoiceQualityAssist/Ymm4VoiceQualityAssist.dll` がある状態にします。
旧候補版がある場合は、別の場所へ退避してから同名フォルダーを置き換えてください。同じDLLのコピーを複数のプラグインフォルダーに置かないでください。
このZIPは `.ymme` 形式ではありません。YMM4やVOICEVOXのDLL、辞書、フォントは含めていません。

再起動後、ツールメニューのユーティリティ内で `Voice Quality Assist` が表示されるか確認します。表示されない場合は、YMM4側のプラグイン読み込みエラーを確認し、原本の編集はそのまま続けて構いません。

## まず試すこと

通常のVOICEVOX音声を再生し、コピーしたプロジェクトで比較用の基準音声を確認してください。
ボイスアイテムの字幕側の映像エフェクトに「発音補助」を追加すると、そのアイテムが補助対象になります。無効・未設定のアイテムを自動で一括変更するものではありません。

ゼロポーズ指定はSerifの `<w0>` です。既存の読み・アクセント句・PauseMoraに一意に対応できる位置だけ適用します。文字間へ適当に入れれば必ずポーズが消える、という機能ではありません。対応できない場合は保留になり、Toolに理由を表示します。
Hatsuonに `<w0>` を直接書き込まないでください。helperや抑揚のルールも、元の台詞へ隠し情報として埋め込まず発音補助Effect側に保存します。

補助あり／なしを聴き比べ、Effectの無効化・再有効化、Serif/Hatsuonの変更、保存・再読込を確認してください。初回失敗時に通常の手動調整済み音声を勝手に再生成しないようにしています。

## LLMと往復する

Toolの「LLMレビュー用プロンプトをエクスポート」で、レビュー指示と現在のTimelineのボイス一覧を含むテキストを保存します。同じフォルダーへ `.review-<session>.json` も保存します。**この元JSONを削除しないでください。** 再起動後のImportに必要です。

プロンプトに含まれる台詞・前後文・キャラクター名などは、利用するLLMへ渡す内容です。機密情報がないか確認してから手動で渡してください。プラグインが外部LLMへ自動送信する機能はありません。

LLMの返答は `ymm4.voice-corrections.v0` のJSONだけを保存し、「LLMレビュー結果をインポート」で読み込みます。同じセッションを保持していない場合は、対応する `.review-<session>.json` を選択します。別の時点で個別出力したJSONではセッションが一致しない場合があります。

EXACTの項目だけ選択でき、STALE / MISSING / AMBIGUOUSは適用しません。変更前後を確認し、必要な項目だけ適用してください。Undo/Redoで戻した設定に合わせ、音声は再生成されます。音声生成が完了したことを確認してから比較・保存してください。

## 候補版の制限

- 読み変換と既存moraの対応が曖昧な場合、helperや境界は自動適用しません。
- `<w100>` など別の公式タグを含むSerifの境界書き換えは拒否します。タグを消して再構築しません。
- 抑揚は None / LightRise / LightFall / Hold の範囲です。自然さや好みは実音声で確認が必要です。
- helperや抑揚の詳細GUIはまだ最終調整前です。候補版では構造化Importを主な設定経路にできます。
- CSVは閲覧用で、Importの正本ではありません。数式に見える文字列には先頭にアポストロフィを付け、表計算ソフトによる式の評価を抑止します。元のSerifやJSONは変更しません。
- 入力JSONは8 MiBまでです。未対応の項目や不正データを無視して適用せず、エラーとして止めます。
- 実VOICEVOXでの聴取、ファイル選択、Import一覧の操作感、一般配布ライセンスの最終確認は公開リリース前に残っています。

## 戻す・外す

適用直後はYMM4の「元に戻す」を使います。生成中の設定変更は古い結果を破棄して再処理します。
不具合が起きた場合は上書き保存せず、テスト用コピーを閉じ、バックアップへ戻ってください。
アンインストールはYMM4終了後にこのプラグインフォルダーだけを退避します。必要なプロジェクトから発音補助Effectを外して別名保存しておくと、プラグインのない環境へ渡しやすくなります。

`manifest.json` にソースSHA、CI run ID、DLLのSHA256を記録しています。問題報告にはこの3つと、操作・期待結果・実際の結果を添えてください。台詞の公開は不要です。
